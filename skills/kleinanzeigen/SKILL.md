# Kleinanzeigen Skill

Этот скилл предоставляет интерфейс к локальному адаптеру `kleinanzeigen_bot`.

## Основные команды

Скилл использует Python-скрипт `scripts/manage_ads.py` для взаимодействия с адаптером. Вызывайте его через `python3 skills/kleinanzeigen/scripts/manage_ads.py`.

### 1. Список моих объявлений

Получить краткий список всех активных объявлений (ID, заголовок, цена, статус).

```bash
python3 skills/kleinanzeigen/scripts/manage_ads.py list
```

### 2. Статистика (просмотры и избранное)

Получить детальную статистику по всем объявлениям (количество просмотров, избранное, дата окончания).
**Примечание:** Этот процесс может занять до 30-60 секунд, так как требует локального запуска браузера для скрапинга.

```bash
python3 skills/kleinanzeigen/scripts/manage_ads.py stats
```

### 3. Детали объявления

Получить полное описание, категорию и другие данные по конкретному ID.

```bash
python3 skills/kleinanzeigen/scripts/manage_ads.py details <AD_ID>
```

## Рабочий процесс (Workflow)

1. **Поиск ID**: Если пользователь просит что-то сделать с «объявлением про iPhone», сначала выполните `list`, чтобы найти соответствующий ID.
2. **Проверка успеха**: Скрипт всегда возвращает JSON. Если в ответе есть поле `"error"`, сообщите об этом пользователю.
3. **Локальные пути**: Скрипт настроен на работу с `/Users/max/kleinanzeigen_bot`.

## Ограничения

- Скилл работает только на этой машине, так как требует доступа к локальному коду адаптера и конфигурации `accounts.yaml`.
- Для работы необходимы установленные пакеты: `pydantic`, `langchain_core`, `requests`, `pyyaml`.
